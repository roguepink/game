# ACORN DIRT GP（どんぐりダートGP）

`index.html` を開くだけで遊べる、山道オフロードバイクの 3D カートレース風ゲームです。

- ファイルは `index.html` 1枚だけ。3D は **three.js（CDN）だけ**を使い、画像・音声・モデルなどの外部ファイルはありません。
  コース、バイク、ライダー、効果音、BGM はすべてコードで生成しています。
- 開いた瞬間から自動デモ（AIがレース中）が流れ、**何かキーを押す／クリックすると自分で遊べます**。
- キャラクター・名前・アイテムはすべてオリジナルです。

## 操作

| キー | 動作 |
| --- | --- |
| ↑ / W | アクセル |
| ↓ / S | ブレーキ・バック |
| ← → / A D | ハンドル |
| Shift（C, Z） | ドリフト（火花が 青→橙→桃 に変わったら離すとターボ）／ 空中でトリック（着地でブースト） |
| Space（X） | アイテム（おにぎりターボ・どんぐりショット・どろだんご） |
| H / M / P / R / Esc / Q / F | ヘルプ / ミュート / ポーズ / リスタート / タイトルへ / 画質 / フルスクリーン |

ゲームパッド、スマホ（横向き・画面ボタン）にも対応しています。

## コース

山のふもとをスタートし、橋を渡り、ヘアピンの連続で山頂の尾根へ登り、大ジャンプで谷へ飛び出して、
トンネルのある下り坂を抜けてゴールに戻る 1周約 3.2km（ゲーム内単位）× 3周です。
ブーストパッド、泥、ジャンプ台、アイテムボックスがあります。

## 動かすために

- インターネット接続が必要です（three.js r128 を cdnjs / jsDelivr / unpkg のどれかから読み込みます）。
- WebGL が使えるブラウザ（Chrome / Edge / Firefox / Safari の最近のバージョン）で動きます。
