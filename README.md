# GRIT TRAIL（グリット・トレイル）

障害物だらけの一本道を、ゴールまで駆け抜ける 3D オフロードバイクレースです。`index.html` を開くだけで遊べます。

- ファイルは `index.html` 1枚です。3D は **three.js（CDN）だけ**を使います。画像・音声・モデルなどの外部ファイルはありません。
  コース、地形、バイク、ライダー、砂ぼこり、水しぶき、エンジン音はすべてコードで生成しています。
- 開くと自動デモ（AI 同士のレース）が流れます。何かキーを押すか、画面をタップするとステージ選択に進みます。
- 登場する名前はすべて架空のものです。

## ルール

- 周回はありません。長い一本道のコースをスタートからゴールまで走ります（1ステージ 2.6〜4.9 km、およそ 2〜4 分）。
- 6台で走り、**2位以内でゴールすると次のステージが開きます**。全10ステージで、ステージが進むほどライバルは速く、ミスが少なくなります。
- 進んだステージとベスト記録はブラウザに保存されます。

## 操作

| 操作 | キーボード | スマホ（横向き） |
| --- | --- | --- |
| アクセル（押している間だけ加速、離すと減速） | ↑ / W / Space | 画面の右側を押し続ける |
| 左右に曲がる | ← → / A D | 左下の ◀ ▶ |
| ブレーキ | ↓ / S | （アクセルを離すと減速） |
| ポーズ / リトライ / タイトル | P / R / Esc | 上の II ボタン |
| 操作説明 / 音 / 全画面 / 画質 | H / M / F / Q | ― |

ゲームパッドにも対応しています（A または RT がアクセル、左スティックでハンドル）。

## コースと障害物

- **岩・倒木・切り株・サボテン・立ち木**：スピードを出したまま当たるとクラッシュします。ライダーが投げ出され、数秒のロスになります。
- **小石・丸太・わら・ドラム缶**：乗り越えたり、はね飛ばしたりできますが減速します。
- **川・水たまり・川の中の区間**：水しぶきが上がり、スピードが落ちます。
- **泥・砂・砂利・ガレ場**：泥と砂は重く、砂利はすべりやすく、ガレ場は激しく揺れます。避けるラインを選ぶと速く走れます。
- **ジャンプ台・テーブルトップ・ダブル・丘越え・段差の飛び降り・でこぼこ道**：空中でアクセルを押すと前輪が上がり、離すと下がります。着地面に車体を合わせると「ナイス着地」で加速します。

## 動かすために

- 初回はインターネット接続が必要です。three.js r128 を cdnjs / jsDelivr / unpkg のどれかから読み込み、どれも使えないときは `vendor/three.min.js` を使います。
- WebGL が使えるブラウザ（Chrome / Edge / Firefox / Safari の最近のバージョン）で動きます。重いときは自動で画質が下がります（Q キーでも切り替えられます）。

## スマホ・アプリとして使う（PWA）

HTTPS で公開すると、ホーム画面に追加してアプリのように全画面・横向きで遊べます。一度開けばオフラインでも起動します。

- 公開: GitHub Pages（Settings → Pages → Branch を `main` / root）などで、このリポジトリのルートをそのまま公開します。
- iPhone: Safari で開く → 共有 → 「ホーム画面に追加」（iPhone の Safari はページの全画面表示に対応していないため、全画面で遊ぶにはホーム画面から開きます）
- Android: Chrome で開く → メニュー → 「アプリをインストール」/「ホーム画面に追加」（ブラウザで開いても最初のタップで全画面になります）
- ファイル: `index.html`（本体）、`manifest.webmanifest`、`sw.js`（オフライン用）、`icons/`、`vendor/three.min.js`（CDN が使えないときの予備、MIT）
